A pasta raw data inclui os dados de Mimosa validados pelo laboratório, a tabela com dados de coletas fornecidos pelo laboratório do Ryan e a tabela gerada pela extração de dados feita com o robô.

Filtered_mimosa_table.csv: arquivo com dados selecionados apenas pra mimosa, pra analises testes de evolução molecular e de brms da BEPE.
Mimoseae_generos.csv: inclui todos os gêneros da Tribo Mimoseae e número de espécies em cada um. 
Mimoseae_species_nameclean.csv: tabela com todos os nomes de espécies validados com TNRS. 
mimoseae_subset_clean.csv: tabela com sorteio de espécies e dados morfológicos validados.
